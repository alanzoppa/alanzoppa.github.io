03The Metaphor

Once, I managed eight interns

Give them room to surprise you

They picked a ridiculous team name to make fun of me. It was great.

They'll overengineer

One wrote a stored SQL procedure for what should have been a 12-line Rails controller.

They need limits that would seem obvious

Gym clothes in the office. Missed Meetings. No tests. Things you didn't think you'd have to say.

These aren't competence problems. They're judgment problems.
04The Parallel

Coding agents have a lot of the same gaps

  1. Overengineering Reaches for a clever solution when a boring one was right there.
  2. Reinvents the wheel Won't reach for a library or third-party solution without being told to look.
  3. Needs reminders for the obvious Won't check the build, run tests, or push unless you say so explicitly.
  4. No instinct for what's sensitive Credentials, secrets, private data — not on the radar without a rule.
  5. Won't tell you you're wrong If the solution means forking systemd it'll do that.

Every one of these is a judgment gap, not a capability gap. Agents can do these things — they just don't know they should.

06The Fix

The solution isn't smarter models — it's better guardrails

  • ✓
    MUST parallelize with subagents Dispatching is the default. Solo work is the exception.
  • ✓
    Push after successful complex changes Commit AND push. All tests green first.
  • ✓
    Test new functionality Write automated tests as you go. Regression tests where needed.
  • ✓
    Always specify the subagent type "I'll dispatch X to @build, Y to @explore."
  • ✓
    Type safety is preferred When the language supports it. Free correctness, free docs.
  • ✓
    Don't reinvent the wheel Prefer robust libraries. Don't re-test library functionality.
07The Idea

Embeddings in only three dimensions

An embedding is just a coordinate. Every word, sentence, or document gets a position in a high-dimensional space — and similar meanings land near each other.

The angle between two vectors (cosine distance) is their semantic distance. Near 0° → same meaning. Near 180° → opposite.

uncle−man+woman≈aunt
"Sad" is close to "unhappy" even though they share no letters. You're matching meaning, not keywords.

09Closing

Five takeaways

  1. $20/month gets you a shocking number of tokens
    Ollama Pro is nearly inexhaustible for a single developer.
  2. Open-weights models are competitive
    GLM 5.1, Kimi k2.6, DeepSeek v4 — the Chinese labs are shipping.
  3. Plan-then-execute works at scale
    Big model plans, smaller models execute, explicit task-to-model mapping.
  4. Guardrails matter more than intelligence
    Clear mandates — not suggestions — close the judgment gap.
  5. I built something I wouldn't have written by hand
    Mnestic: scattered notes → queryable agent knowledge base.
